De 0.6.0 a 0.28.0 no cambia ninguna operación ni esquema que ya consumía la web, salvo ese `sport_habits`, el campo `nutrition_habits` del perfil y los esquemas de eventos de 0.26.0: `MyEventsResponse.items` pasa a `OwnEventResponse` (con `fee`, `fee_updated_at` y `registration_count`), `EventAggregateResponse` agrega `fee` y `fee_updated_at`, `EventDetailResponse` agrega `registration_count` (solo para el propietario), `PublishedEventItem` agrega `fee` y `EventFee` queda en `{amount, currency}` (sin `billing_unit`); los fixtures de HU022–HU024 se adaptaron (0.17.0 agrega el método `GET` a `/v1/events`, cuyo `POST` de HU021 no cambia). `POST /v1/users` no cambia desde 0.2.0.
